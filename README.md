# 📊 SQL Data Preparation & Staging

A data preparation and modeling repository built in *SSMS* to transform raw enterprise datasets into analytical views.

## 🚀 Key Highlights
* *SQL Data Prep & Staging:* Ingested raw datasets into *SSMS*, writing SQL cleaning scripts to eliminate duplicates, handle missing values, and standardize data types.
* *Analytical Modeling:* Engineered advanced SQL queries (CTEs, Joins, Window Functions) to build staging views for ad-hoc querying and operational reporting.

## 🛠️ Tech Stack
SQL • T-SQL • SSMS
